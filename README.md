# PulseFrame

PulseFrame is a framework for converting physiological time-series signals (ECG/PPG) into 2D imaging representations (GAF, RP, CWT) for downstream deep learning models.

## Project Structure
- `src/`: Core modular code for signal windowing and image transformations.
- `notebooks/`: Exploratory analysis and verification notebooks.
- `progress.md`: Daily and weekly progress updates.
